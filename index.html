AI Readiness & Skills Scan

The team layer on its own — six readiness dimensions scored 1–5 with the weakest link setting the ceiling, plus a seven-capability team skill scan whose required levels rise with their 12-month ambition. Output: readiness scorecard, skills profile and a phased gap-closure roadmap. ~30 minutes, and a deliverable in its own right.

Assess Toolkit

Everything in one engagement. Team module as above; add a workflow for each area you're assessing (operating model, run-capability scan, approvals, systems, data, safeguards); add use cases inside each workflow (readiness scoring and a £ value model each). Two or more use cases unlocks the portfolio: ranking, waves and the aggregate business case, with every use case showing which team-level gap gates it.
