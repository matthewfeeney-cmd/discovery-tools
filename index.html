How they chain (Assess phase): screen many workflows → pick the winners → size the £ → prove the path. Discovery Screen (Prioritise · light) → Value Assessment (Validate / Build) → Mini Op Model (one workflow). Each tool works standalone too. Feedback → #discovery-tools or Matt.
1 · Prioritise — organisation + workflows

AI Readiness Assessment

Two layers. Organisation readiness (~20 min, once): six dimensions — strategy, data, technology, skills, governance, adoption — scored 1–5 and weighted 10/20/70, with the weakest link setting the ceiling against their 12-month target. Use cases: value × readiness per workflow, £ at stake, build-vs-buy. Output: readiness scorecard, phased gap-closure roadmap, and a ranked backlog showing which organisation gap gates each candidate.

Open → 2 · Validate / Build — the £ case

Value Assessment Tool

Baseline of today’s cost → potential value → realistic value (discounted for adoption, effectiveness, integration) → costs → go / adjust / stop. Produces a £ value case a CFO can interrogate — the scope of the Build.

Open → 3 · Assess + Build — one workflow

Mini Op Model

Light: ~30 min — process · people · tech signals rated by hand, readiness score, one-pager. Deep: 3–5 days alongside the build — the approvals map, named roles, system and data inventories RATE the signals automatically; plus safeguards register and POC-vs-production log. Every gap compiles into an owned action, phased Now → before MVP → before go-live — ready to paste into a plan or board.
