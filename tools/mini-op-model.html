How this works

The build proves the workflow works; this form captures what it would take to run it for real — the "mini operating model" Build promises: who approves it, who runs it, what it connects to, what skills it needs. Fill it from short conversations with the people named in each section. Rate each signal as you learn it; if you can't answer, pick red — unknowns are blockers until someone answers them. Value is handled separately in the Value Assessment Tool.

Light — ~30 min, one pass
Deep — 3–5 days, run alongside the build

4Safeguards — what it must never do DEEP

For every action the AI takes, name the worst case and who stays in control. The safe default is propose → a person reviews → apply; an action only earns direct execution once its track record justifies it. Ask the team: "what must never happen, whatever the case looks like?"
