How this works

Screen each candidate workflow with the person who knows it. Four Value questions, then twelve AI-readiness checks across four dimensions — fit · data · tech · skills. If you can't answer, pick the left option: an unknown is a finding, and the score rises as you learn. You get scores, an indicative £ at stake, a build-vs-buy call and a ranked backlog. Deep-dive the winners with the Value Assessment and Mini Op Model, and bring the top ones to life with quick prototypes on example cases.

FEASIBILITY PROBE — test it, don't assume it DEEP

Two hours, no code: name the one thing you're unsure AI can do, collect ~10 real cases (a few typical, a few harder, a couple awkward), paste them into a model playground with a rough brief, and score what comes back. Once 5+ cases are scored, the tested result replaces the "has this been done before?" answer in the readiness score — measured beats assumed. Credible = a knowledgeable person would trust it as a starting point.
